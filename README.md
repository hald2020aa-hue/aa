# قارئ كامل | Qari Kamel

مشروع Android أصلي مستقل أُنشئ بعد **تحليل ساكن** لملف APK للتطبيق `org.hamak.mangareader`، الإصدار `2.0.7.6.11`، للمساعدة في إعادة تنفيذ الوظائف المشاهدة في التطبيق، **وليس** فك حماية التطبيق أو إعادة نشر كوده وموارده المحمية.

## حالة المشروع

**نسخة مصدرية أولية وظيفية (v0.1.0)، لم تُبنَ إلى APK ولم تُختبر على جهاز فعلي.** البيئة التي أُنشئ فيها هذا المشروع لا تحتوي على Android SDK أو Gradle وممنوعة من تنزيل الاعتمادات. لذلك لا يصح اعتباره نسخة مطابقة للأصل أو إصدارًا جاهزًا للنشر. مسار GitHub Actions مرفق ويظهر أخطاء البناء إن وجدت.

## المكونات التي تم تنفيذها

- واجهة عربية داكنة مع تخطيط شبكة يتكيف مع الهاتف والهواتف القابلة للطي.
- مكتبة مع المفضلة، أحدث العناوين، وعدد الفصول.
- تخزين SQLite للمصادر، والمانجا، والفصول، والتقدم في القراءة وحالة التنزيل.
- إضافة وتعديل وحذف عدد غير محدد نظريًا من المواقع، بما فيها مواقع البالغين التي يسمح القانون وشروطها بالوصول إليها؛ خيار 18+ مجرد تصنيف للمصدر.
- محرك HTML/CSS ومحرك JSON/REST قابلان للتهيئة للبحث، الكتالوج، استخراج الفصول وصور الصفحات؛ مثال تهيئة داخل `assets/source_template.json`.
- متصفح WebView لتسجيل الدخول اليدوي وتخزين Cookies؛ *لا يعني ذلك تجاوز Cloudflare أو DRM*.
- قارئ تمرير عمودي وقارئ صفحة واحدة مع التكبير، انتقال بين الفصول وتسجيل آخر صفحة.
- تنزيل الفصول باستخدام WorkManager، وحفظ الصفحات محليًا، مع إمكانية المحاولة مجددًا وإيقاف العمل.
- استيراد `CBZ/ZIP` يحتوي على صور وصفحات مجمعة حسب المجلد، وحماية من تجاوز مسارات ZIP وحدود للحجم وعدد الصور.
- استيراد وتصدير ملفات JSON للمصادر والمكتبة والتقدم في القراءة.

## قيود معروفة ومهمة

1. **لا توجد مطابقة مضمونة للواجهات أو السلوك الأصلي:** لم تُقارن الشاشات تفاعليًا بالفيديوهات، ولم يُشغَّل ملف APK في محاكي أو هاتف.
2. المواقع التي تحتاج JavaScript لتوليد الفصول/الصور، أو تسجيل دخول خاص، أو API خاص، تتطلب موصلًا مخصصًا. المتصفح موجود، لكن لا يُحوِّل HTML الديناميكي تلقائيًا إلى نتائج الكتالوج.
3. لا تُضمَّن مواقع مصادر مثبتة مسبقًا؛ المستخدم يضيف المصادر ومحددات CSS بنفسه.
4. لا يدعم CBR/RAR أو الملفات المشفرة ولا التحميل المتوازي المتقدم على مستوى الصفحة، ولا المزامنة السحابية للحساب، ولا تحديث الفصول التلقائي.
5. استعادة ملفات JSON تنقل المراجع المحلية لا صور الأرشيف ذاتها؛ الأرشيفات يجب نقلها أيضًا عند تغيير الجهاز.
6. أعطال الشبكة والقيود والصفحات المتغيرة قد تؤثر في البحث والتنزيل؛ نتيجة WorkManager على الجهاز لم تُختبر.
7. التنزيلات عبر WorkManager محدودة بسياسات Android ومهلة العامل؛ الفصول الكبيرة تحتاج عاملاً من نوع `long-running` مع إشعار تقدّم.
8. لم تُنسخ أي أيقونات أو مواد فنية من APK الأصلي.

## البناء

### GitHub Actions — أسهل خيار
1. فك الملف ZIP، ثم ارفع كل محتويات مجلد المشروع إلى مستودع GitHub **خاص بك**.
2. افتح `Actions` ثم سير العمل `Android build` واختر `Run workflow` (أو ادفع Commit إلى `main`).
3. إن نجحت خطوة `Build debug APK`، افتح نتيجة التشغيل وحمّل `QariKamel-build`، وبداخله `app-debug.apk`.
4. إن فشل البناء، افتح سجل الخطأ. **وجود سير العمل لا يعني أن APK قد تم بناؤه هنا.**

### على جهاز به Android Studio
- افتح جذر المشروع واسمح بمزامنة Gradle (AGP 8.7.3 / Gradle 8.9 / JDK 17 / SDK 35).
- اختر `Build > Build APK(s)`.
- توجد اعتمادات `jsoup:1.18.3` و`androidx.work:work-runtime:2.10.2` يتم تنزيلها عند المزامنة.

## صيغة المصدر

مثال داخل `app/src/main/assets/source_template.json`. أهم الحقول:
- `baseUrl`: رابط HTTPS للموقع.
- `searchPath`, `catalogPath`: مسارات تستبدل `{query}` و`{page}`.
- `itemSelector`, `titleSelector`, `linkSelector`, `coverSelector`: استخلاص نتائج التصفح.
- `chapterSelector`, `chapterTitleSelector`, `chapterLinkSelector`: روابط الفصول.
- `pageSelector`, `pageUrlAttribute`: صور القارئ.
- `adult`: تمييز محتوى البالغين؛ لا يفتح مواقع أو محتوى بشكل تلقائي.
- `format`: `html` أو `json`. في JSON استخدم `itemsPath` و`jsonTitlePath` و`jsonLinkPath` و`jsonCoverPath`، ثم `chaptersPath` و`jsonChapterNamePath` و`jsonChapterLinkPath`، ثم `pagesPath` و`jsonPageLinkPath`. المسارات تتبع حقول JSON مفصولة بالنقطة، مثل `data.results`.

## المراجعة الأمنية

- HTTPS فقط في طلبات الشبكة، والاتصالات غير المشفرة معطلة في Manifest.
- لا تخزين لبيانات الحسابات أو كلمات المرور داخل تطبيق النسخة الجديدة.
- مساحة تخزين خاصة بالتطبيق، مع اختيار ملفات من Android Storage Access Framework.
- يمنع ZIP Slip أثناء الاستيراد، وتُطبق حدود تقريبية لحجم الأرشيف والملفات.
- تنفيذ JavaScript في المتصفح يُستخدم فقط لتحميل مواقع يفتحها المستخدم؛ لا تُمكَّن واجهات JavaScript من نوع `addJavascriptInterface`.
